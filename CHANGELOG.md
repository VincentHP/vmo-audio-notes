# Changelog

## 1.0.0

- Start and stop Obsidian’s native recorder through a companion button or command.
- Save timestamped English transcripts and local Qwen summaries beside the starting note.
- Add a persistent processing queue, cancellation, pause/resume, and checkpoint-based retries.
- Preserve original recordings, unsaved editor content, and edits to generated notes.
- Provide guided setup for Whisper, FFmpeg, and the English transcription model.
- Include a dependency-free build, 21 automated checks, and GitHub Actions verification.
